API

Agent

An agent account in the workspace: list, create, read, rename or change the icon of one, or delete it with its addresses and messages.

Operations

Every route this entity exposes. Each route links to its own reference on this page.

Method Route SDK operation Returns
POST /agents create The new agent
GET /agents list The agents
GET /agents/{id} load The agent
DELETE /agents/{id} remove The agent is gone
PATCH /agents/{id} update The changed agent
