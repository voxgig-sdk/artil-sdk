API

Address

An agent's email address, phone number, Telegram bot or Slack bot: list, add, read, change or remove one, or make it the one its channel sends from (primary).

Operations

Every route this entity exposes. Each route links to its own reference on this page.

Method Route SDK operation Returns
POST /agents/{id}/addresses/{addressId}/primary create The address is primary
POST /agents/{id}/addresses create The new address
GET /agents/{id}/addresses list The addresses
GET /agents/{id}/addresses/{addressId} load The address
DELETE /agents/{id}/addresses/{addressId} remove The address is gone
PATCH /agents/{id}/addresses/{addressId} update The changed address

value string Yes The email address, phone number, Telegram bot's @username, or Slack bot's workspace and member ids
