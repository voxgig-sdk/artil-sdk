API

Webhook

Where an agent's events are posted: list, add or remove one. Adding one returns its signing secret.

Operations

Every route this entity exposes. Each route links to its own reference on this page.

Method Route SDK operation Returns
POST /agents/{id}/webhooks create The webhook and its secret
GET /agents/{id}/webhooks list The webhooks
DELETE /agents/{id}/webhooks/{webhookId} remove Events are no longer posted there
