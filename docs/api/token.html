API

Token

The tokens members made for an agent, never their values: list them or revoke one.

Operations

Every route this entity exposes. Each route links to its own reference on this page.

Method Route SDK operation Returns
GET /agents/{id}/tokens list The tokens
DELETE /agents/{id}/tokens/{tokenId} remove The token no longer works
