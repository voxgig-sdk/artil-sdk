API

Message

An email, text, Telegram or Slack message an agent received or sent: list them (by channel, direction or counterpart), read one, or send one, which can answer (replyTo) or pass on (forward) another.

Operations

Every route this entity exposes. Each route links to its own reference on this page.

Method Route SDK operation Returns
POST /agents/{id}/messages create The sent message
GET /agents/{id}/messages list The messages
GET /agents/{id}/messages/{messageId} load The message

Authentication: bearer token (token) or oauth2 (oauth).
